# 오늘의 급식 (전국 학교 급식 & 간식 추천 웹사이트)

전국 초·중·고등학교 실시간 급식 식단표, 알레르기 알림, 칼로리 및 영양정보 조회, 맞춤 간식 추천 챗봇 서비스입니다.  
**순수 정적 웹 애플리케이션(Static Web App)**으로 변환되어 GitHub Pages 등 정적 호스팅 서비스에서 서버 없이 100% 동작합니다.

---

## 🚀 GitHub Pages 배포 방법 (초간단)

### 방법 1: GitHub Actions 자동 배포 (권장)

이미 프로젝트 내에 `.github/workflows/deploy.yml` 파일이 설정되어 있습니다.

1. 이 소스 코드를 GitHub 저장소(Repository)의 `main` 브랜치에 Push합니다.
2. GitHub 저장소 페이지의 **Settings** > **Pages** 메뉴로 이동합니다.
3. **Build and deployment** 섹션의 **Source**를 **`GitHub Actions`**로 선택합니다.
4. 잠시 후 상단에 표시되는 배포 URL(예: `https://<username>.github.io/<repo-name>/`)로 접속하면 배포가 완료됩니다!

---

### 방법 2: 로컬에서 빌드 후 배포하기

```bash
# 1. 의존성 설치
npm install

# 2. 정적 웹사이트 빌드 (dist 폴더 생성)
npm run build

# 3. 로컬에서 빌드 결과물 미리보기
npm run preview
```

## 🌟 주요 기능

- **전국 학교 검색**: 교육부 NEIS 오픈 API 실시간 연동 (전국 17개 시·도 교육청 및 초·중·고)
- **날짜 탐색**: 달력 선택기, 이전/다음 날 이동, 주간 식단표(월~금) 한눈에 보기
- **알레르기 안심 알림**: 19종 교육부 표준 알레르기 성분 필터링 및 강조 배지
- **영양 성분 & 칼로리**: 탄·단·지 에너지 비율 및 비타민, 칼슘 분석
- **식재료 원산지 정보**: 국내산/수입산 축산물 및 수산물 표기
- **간식 추천 챗봇 (냠냠이)**: 오늘 급식 식단과 알레르기에 맞춤 추천 (클라이언트 완전 독립 실행)
- **식단 복사 및 공유**: 카카오톡/문자 양식 원클릭 복사
